# CRM---TR-FEGO-PAGO
Sistema de CRM desenvolvido para empresas que prestam serviços de tráfego pago. Os clientes realizam o preenchimento de um formulário, e, após o envio, suas informações preenchem um banco de dados. A partir desses dados, a empresa responsável pode analisar os registros e entrar em contato com os clientes para dar continuidade ao atendimento.
